MaixCAM-Pro (RISC-V) 移植指南
===============================

=== 目标设备 ===

  型号: Sipeed MaixCAM-Pro
  SoC: Sophgo SG2002 (CVITEK CV1800B)
  CPU: RISC-V 64-bit rv64gc + XThead 向量扩展
  OS: Buildroot Linux 2023.11.2
  libc: musl (非 glibc)
  浮点: 硬件双精度 (LP64D ABI)
  Python: MaixPy v4.12.5

=== 准备工作 ===

1. 下载 RISC-V musl 交叉编译工具链:

     浏览器打开: https://musl.cc/
     下载: riscv64-linux-musl-cross.tgz

     或命令行:
     wget https://musl.cc/riscv64-linux-musl-cross.tgz
     tar xzf riscv64-linux-musl-cross.tgz -C /opt
     export PATH="/opt/riscv64-linux-musl-cross/bin:$PATH"

     验证安装:
     riscv64-linux-musl-gcc --version

2. 安装 adb (Android Debug Bridge):

     Ubuntu/Debian: sudo apt install adb
     Windows: 下载 platform-tools, 添加到 PATH

3. 连接设备:

     USB 连接 MaixCAM-Pro 到 PC
     adb devices           # 应列出设备
     adb shell             # 进入设备 shell 验证

=== 编译 ===

  方法一: 编译为可执行文件 (测试用)

    riscv64-linux-musl-gcc -std=c99 -O2 -static \
      -o test_linalg test_linalg.c tiny_linalg.c -lm

  方法二: 编译为静态库 (供其他模块链接)

    riscv64-linux-musl-gcc -std=c99 -O2 -c tiny_linalg.c -o tiny_linalg_riscv.o
    riscv64-linux-musl-ar rcs libtiny_linalg_riscv.a tiny_linalg_riscv.o

  编译选项说明:
    -std=c99       使用 C99 标准 (restrict 关键字)
    -O2            优化级别 (速度和体积平衡)
    -static        静态链接 (推荐, 避免 musl 版本不匹配)
    -lm            链接数学库 (musl 的 libm)

=== 部署 ===

  # 推送文件
  adb push test_linalg /root/

  # 赋予执行权限
  adb shell chmod +x /root/test_linalg

  # 运行
  adb shell /root/test_linalg

  # 期望输出: "65 passed, 0 failed"

=== 集成到 maixapp 应用框架 ===

  MaixCAM-Pro 的应用放在 /maixapp/apps/<应用名>/

  创建一个导航应用:

    mkdir -p nav_app
    cat > nav_app/app.yaml << EOF
    id: nav_app
    name: 导航解算
    version: 1.0.0
    icon: icon.png
    description: 多传感器融合导航
    EOF

    将 libtiny_linalg_riscv.a 和 nav_main 放入 nav_app/
    推送到设备:
    adb push nav_app /maixapp/apps/nav_app

  应用入口两种方式:
    a) main.py 调用 C 模块 (推荐, 可复用 MaixPy 的 camera/imu API)
    b) 纯 C 可执行文件, 通过 app.yaml 指定

=== 与 MaixPy 混合编程 ===

  C 代码可以作为 Python C 扩展或独立进程运行。

  推荐方案: C 独立进程 + Python 主控

    Python 端:
    - 用 MaixPy 的 camera / imu / display 模块采集数据
    - 通过 subprocess 或 IPC 调用 C 导航解算进程
    - 或使用 ctypes 加载 libtiny_linalg_riscv.a

  如果只需要 IMU 数据:
    from maix.ext_dev import imu
    imu_dev = imu.IMU("default")
    # 读取 accel/gyro, 传给 C 端

=== PC 端模拟测试 ===

  在 Ubuntu 上安装 x86 musl 工具链, 提前验证 musl 兼容性:

    sudo apt install musl-tools
    musl-gcc -std=c99 -O2 -static \
      -o test_linalg_musl test_linalg.c tiny_linalg.c -lm
    ./test_linalg_musl

  这是最接近目标设备行为的本地测试方式。

=== 常见问题 ===

  Q: 编译报 "undefined reference to M_PI"
  A: musl 的 math.h 默认不定义 M_PI。
     在 #include <math.h> 后加:
     #ifndef M_PI
     #define M_PI 3.14159265358979323846
     #endif

  Q: 运行时找不到动态库
  A: 使用 -static 静态链接, 不依赖设备上的 .so

  Q: adb 不识别设备
  A: Windows 需要安装 Zadig 驱动 (WinUSB)
     Linux 需要 udev 规则或 sudo 运行 adb
     MaixCAM-Pro 需要先开机进入系统, 再插 USB

  Q: 浮点精度与 x86 不同
  A: RISC-V 硬件浮点 vs x86 80位扩展精度有差异。
     关键位置已加钳位保护 (acos/sqrt 参数)。
     测试阈值一般设 1e-8 ~ 1e-10, 不应设更严。

  Q: 能用 glibc 交叉编译吗
  A: 不推荐。目标设备是 musl, 用 glibc 交叉编译需要
     目标设备上也装 glibc, 但 Buildroot 默认用 musl

=== 交叉编译工具链备选 ===

  如果 musl.cc 的工具链有问题, 可用以下替代:

  1. Sipeed 官方 SDK:
     https://github.com/sipeed/MaixCDK
     自带 RISC-V musl 工具链

  2. bootlin 工具链:
     https://toolchains.bootlin.com/
     选 riscv64-linux-musl

  3. crosstool-ng 自建:
     适合需要定制编译选项的场景
