tiny_pnp 错误报告
===============
测试日期: 2026-07-25
测试环境: gcc -std=c99 -Wall -Wextra -O2 (Linux x86_64) + musl-gcc (x86 musl)
测试结果: 20 passed, 0 failed (glibc 和 musl 均通过)

修复的 2 个 bug:

----------------------------------------------------------------------
Bug 1: PCA 特征值相等导致控制点退化
----------------------------------------------------------------------
位置: tiny_pnp.c:49-58 (select_control_points)
现象: 8 个 3D 点 (4 个 z=0 方形 + 4 个 z=1.5 菱形) 时,
      EPnP 结果完全错误 (t≈[0,0,0.08] 而非 [0.2,-0.1,3.5]),
      重投影 RMS=802 px, 后续 LM 精化也无法恢复。
原因: 当 3D 点在 x,y 方向方差相等时 (方形 → λ₁=λ₂),
      mat33_symeig 返回的两个特征向量恰好在同一方向,
      导致控制点 c3 和 c4 坐标完全相同:
        c3 = [0.534, 0, 0.75] = c4
      重心坐标矩阵 A=[c1,c2,c3,c4; 1,1,1,1] 奇异,
      mat_solve 返回错误 α → M 矩阵错误 → 零空间向量错误
      → 全部下游结果错误。
修复: 计算控制点后检测 c2,c3,c4 两两距离,
      若任一对 < 1e-10, 用 v1×v2 叉积生成第三个独立方向:
        v1 = c2-c1, v2 = c3-c1 → v3 = v1×v2
        c4 = c1 + √λ₂ * v3/||v3||
      若 λ₂=0 (纯平面点), 则从最大特征值取 10% 作为缩放。

----------------------------------------------------------------------
Bug 2: β 符号歧义 — 相机系 3D 点可能全部 Z<0 (在相机后方)
----------------------------------------------------------------------
位置: tiny_pnp.c:373-391 (步骤 7 之后, 初版无此检查)
现象: 12 个随机点, 任意位姿测试: EPnP 线性解正确,
      但 Horn 绝对定向后 t≈[-0.7, 1.3, -6.9] vs 真值 [0.5, -0.2, 4.0],
      符号和幅值都错误, LM 精化也收敛到错误局部最小。
原因: 距离约束是二次方程: ||c_i^c - c_j^c||² = ||c_i^w - c_j^w||²,
      β 和 -β 给出相同的距离 → 均满足约束。
      但只有一种符号对应点在相机前方 (Z>0)。
      若恢复的 3D 点全部 Z<0, Horn 找到的 R,t 将世界点
      映射到镜像的相机系点 — 仍是有效的 3D 刚体变换,
      但再投影时 Z 为负 → 投影像素与观测完全不匹配。
修复: 恢复相机系 3D 点后, 统计 Z<0 的点数。
      若 > n/2, 将所有点的坐标取反 (等效于 β *= -1):
        if (neg_z > n/2) for (i..) pts3D_c[i] = -pts3D_c[i];
      然后 Horn 绝对定向在正确的半空间进行。

----------------------------------------------------------------------
关键教训
----------------------------------------------------------------------
1. PCA 特征值相等 (退化协方差) 时, mat33_symeig 返回的特征向量
   ANY orthonormal basis in the degenerate subspace — 可能恰好重合。
   控制点生成时必须检测并修复, 叉积是天然的正交化手段。

2. EPnP 的距离约束消除了尺度歧义 (β² 唯一) 但留下了符号歧义 (±β)。
   符号必须通过几何约束 (点在相机前方) 消除, 否则后续的刚体变换
   只能恢复到反射群 O(3) 而非旋转群 SO(3), 导致投影方向反向。
